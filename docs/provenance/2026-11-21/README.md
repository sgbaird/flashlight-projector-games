# Flashlight Projector Games expansion — 2026-11-21

This record covers the local conversation that renamed `sgbaird/flashlight-scripture-maze` to
`sgbaird/flashlight-projector-games` and added Scooby-Doo Pac-Man. The local checkout directory retains its old
name; its origin remote points at the renamed repository. See [raw user prompts](raw-prompts.md).

## Changes

- Moved Scripture Maze code, tests, and documentation into `flashlight_scripture_maze/`; kept compatibility with
  the existing root `art/` and `calibration.yaml`. Added a collection README and updated CI paths and agent guidance.
- Added a pure simulation and pygame projector UI for Scooby-Doo Pac-Man. Reused maze graphs, BFS, calibration,
  detector background learning, camera access, and the threaded camera reader from Scripture Maze.
- Extended detection to retain multiple qualifying spots, preserving the single-brightest-spot API. Each light
  steers a nearby active investigator. The UI shows a light count and supports mouse/keyboard operation.
- Added setup for 1–5 investigators, 0–4 villains, individual cast choices, and Relaxed/Normal/Fast movement.
- Added pellets, Scooby Snack power-ups, scoring, chasing/fleeing villains, captures, and return-home eyes.
  Snack power affects the whole team for eight seconds, shows a countdown, and plays a continuous synth cue.
- Tagged investigators stay out until everyone is out. A two-second pause then resets all actors while retaining
  score and remaining collectibles. Removed individual respawning that attracted villains to the spawn point.
- Changed movement after feedback: characters continue straight, stop at walls, and turn only with explicit input.
  Flashlight steering reaches 18 corridor steps and snaps beams near corner walls to nearby corridors.
- Added local classic-layout import from `masonicGIT/pacman/src/maps.js`; rotated the graph clockwise for landscape,
  preserved its tunnel and 244 pellets, widened projection spacing, outlined walls, and enlarged round character art.
  Fresh checkouts without that local layout automatically use a generated maze.
- Added local portrait installation from files or user-provided URL manifests, transparent two-frame sprite-sheet
  loading, dimming, animation, direction changes, and individual sprite overrides. The supplied cast sheet has five
  columns, open-mouth frames above closed-mouth frames. It came from another session; that session's transcript
  and generation prompt are not available in this conversation and are not reconstructed here.
- Added original synthesized arcade cues and a reproducible local fallback soundtrack composer. Downloaded the
  user-requested interim 8 Bit Composer track locally, converted it to OGG, and configured looping playback.
- Used image generation for a Scooby Snack biscuit icon and installed it locally. The earlier cast-sheet request
  received a generic safety rejection; the later supplied sheet was successfully integrated.
- Opened Muse and Stable Audio locally. Muse redirected to Sympose. Public browser inspection found account-gated
  generation; no track was generated by those services. The interim recording and synthesized fallback are separate.
